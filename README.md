# Задание 1

## Задача 1

### Текст задачи
Составить программу, которая удаляет из списка L за каждым вхождением элемента E один элемент, если такой есть, и он отличен от E.

### Алгоритм решения
1. Создается копия исходного списка `List<int>`.
2. Происходит проход по списку циклом. Если текущий элемент равен `E`, проверяется следующий за ним элемент.
3. Если следующий элемент существует и не равен `E`, он удаляется из списка.
4. Выводится исходный и измененный списки.

# Задание 2

## Задача 1

### Текст задачи
Определить, есть ли в списке L хотя бы один элемент, который равен следующему за ним (по кругу) элементу (первый элемент считать следующим для последнего).

### Алгоритм решения
1. Проверяется, что список не пуст и содержит хотя бы 2 элемента.
2. Запускается цикл по всем узлам `LinkedList`.
3. Для каждого узла определяется следующий: если текущий не последний, берется `Next`, если последний — берется `First` (замыкание в круг).
4. Если значения текущего и следующего совпадают, возвращается `true`. Иначе алгоритм идет дальше. Если дошел до конца — `false`.

# Задание 3

## Задача 1

### Текст задачи
Есть перечень стран, популярных у туристов. Определить для каждой страны, какие из них посетили все n туристов, какие — некоторые из туристов, и какие — никто из туристов.

### Алгоритм решения
1. Создаются три множества `HashSet<string>`.
2. Множество "посетили все" инициализируется странами первого туриста, а затем пересекается (`IntersectWith`) с множествами каждого следующего туриста.
3. Множество "посетил хотя бы один" объединяется (`UnionWith`) со странами всех туристов.
4. Множество "никто не посетил" — это общий список стран минус те, которые посетил хотя бы кто-то (`ExceptWith`).

# Задание 4

## Задача 1

### Текст задачи
Файл содержит текст на русском языке. Напечатать в алфавитном порядке все глухие согласные буквы, которые не входят ровно в одно слово.

### Алгоритм решения
1. Текст из файла разбивается на отдельные слова с помощью цикла.
2. Создается словарь для подсчета: сколько слов содержат каждую из глухих согласных (п, ф, к, т, ш, с, х, ц, ч, щ).
3. Для каждого слова создается множество уникальных букв, чтобы одна и та же буква не считалась дважды в одном слове.
4. Из словаря выбираются те буквы, счетчик которых не равен 1, они сортируются по алфавиту и выводятся.

### Текст задачи
Абитуриенты проходят тестирование по двум предметам. Допускаются набравшие не менее 30 баллов по каждому предмету. Вывести фамилии и имена абитуриентов, потерпевших неудачу, в алфавитном порядке.

3. Созданы два конструктора: по умолчанию и с параметрами.

5. Реализован метод `GetArea()`, возвращающий площадь по формуле `0.5 * a * b`.

# Задание 7

## Задача 1

### Текст задачи
Добавить перегрузку операций для класса RightTriangle:
- Унарные: `++` (увеличивает катеты в 2 раза), `--` (уменьшает катеты в 2 раза).
- Приведение типов: `double` (явная, возвращает площадь), `bool` (неявная, возвращает true, если треугольник существует).
- Бинарные: `<=` и `>=` (сравнивают площади треугольников).

### Алгоритм решения
1. Перегружены унарные операторы `++` и `--`. Они возвращают новый объект `RightTriangle` с умноженными или разделенными катетами.
2. Реализован оператор явного приведения к `double`: возвращает площадь (или -1, если катеты <= 0).
3. Реализован оператор неявного приведения к `bool`: проверяет, что оба катета больше нуля.
4. Перегружены операторы сравнения `<=` и `>=`, которые сравнивают значения площадей через метод `GetArea()`.
